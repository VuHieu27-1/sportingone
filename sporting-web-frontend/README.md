# Sporting ONE - Frontend (React / Vite)

Giao diện Web người dùng & quản trị hệ thống Sporting ONE xây dựng trên nền tảng React 19, Vite, TailwindCSS, Lucide Icons.

## 🚀 Khởi chạy Development
```bash
# 1. Cài đặt thư viện (nếu cần tải lại)
npm install

# 2. Khởi chạy dev server
npm run dev
```

## 📦 Biên dịch Production
```bash
npm run build
npm run preview
```

## ⚙️ Biến môi trường
Cấu hình chi tiết nằm trong file `.env` (tham khảo `.env.example`).
Chứa các biến `VITE_API_BASE_URL`, cấu hình bán kính tìm kiếm sân, thông tin liên hệ hỗ trợ.
