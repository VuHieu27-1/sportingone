# Sporting ONE - Backend (NestJS)

Dự án Backend chính của hệ thống Sporting ONE xây dựng trên nền tảng NestJS, TypeORM, MySQL, PayOS, JWT, Socket.io, Gemini AI.

## 🚀 Khởi chạy Development
```bash
# 1. Cài đặt thư viện (nếu cần tải lại)
npm install

# 2. Khởi chạy dev server
npm run start:dev
```

## 📦 Biên dịch Production
```bash
npm run build
npm run start:prod
```

## ⚙️ Biến môi trường
Cấu hình chi tiết nằm trong file `.env` (tham khảo `.env.example`).
